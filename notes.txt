ISSUES FOUND - NOT FIXED YET
  1. Parser crash takes down the whole scan.
     ntc-templates can raise TextFSMError on output lines they don't recognize (e.g. the
     etherchannel template ends with "^. -> Error"). build_snapshot() runs outside
     _session(), so this is NOT turned into a CollectorError, and scans/runner.py only
     catches CollectorError -> the whole scan stops instead of skipping one device.
     Idea: catch parser errors in fetch_snapshot() and raise CollectorError instead.

  2. IPv6 addresses are never read.
     The "show interfaces" ntc-template only captures IPv4 (IP_ADDRESS regex). On IPv6
     interfaces ip_address is always "". Affects the management-SVI lockout guard in
     l2security and NTP chain following (interface_ips). Fine for the IPv4 lab, but must
     be fixed before managing devices over IPv6 (inventory already allows IPv6).

  3. (minor) err-disabled detail is thrown away.
     parse_show_interfaces keeps only "down" from "down (err-disabled)". Could be useful
     for a future check (port shut by port security / BPDU guard).

PYTHON THINGS LEARNED (quick reference)
  - with + @contextmanager + yield  = RAII: setup before yield, cleanup after
  - no block scope: variables set inside with/if/for live for the whole function
  - objects are passed by reference: functions can modify a dict/object in place
  - dict.get(key, default), dict.setdefault(key, default), dict/list comprehensions
  - A if cond else B  = cond ? A : B
  - zip(a, b) walks two lists side by side
  - lambda, passing functions as values (str.lower), setattr(obj, "field", value)
  - walrus  if m := re.fullmatch(...):   = assign and test in one go
